## 注意点・未確定事項

- SPEC.md第45節の「Phase 1完成条件」は対戦プロトタイプ全体、第46節のPhase 1は基盤実装を指す。本資料では第46節の番号を採用している。
- Guardは初期Playable要件にも含まれるため、単純な状態と軽減処理をPhase 4〜5で扱い、Phase 7で拡張する計画とした。
- Jolt v5.3.0、ImGui v1.91.9bをコミット固定で取得する。glTF解析にはcgltf v1.15を固定して同梱した。
- Visual Studio 2026で検証済み。仕様書が想定するVisual Studio 2022ではまだ検証していない。
- 1フレームごとにGPU完了を待つ初期構成。物理姿勢の描画補間や高度な最適化は未実装。
- モデルは初期のローポリ版。男女で共通の物理寸法を使い、体格差・髪や衣服の独立した物理・指ボーンは未実装。
- GLBローダーは単一メッシュ・11ボーン・単色マテリアル・3クリップの制作仕様に限定する。任意のglTF、テクスチャ、Morph、動的なTranslation / Scaleは対象外。
- `docs/references/` はローカル専用でGit除外。新しいチェックアウトではこの画像へのリンクが存在しない場合がある。モデルの再生成とビルドに参考画像は不要。
- 命中位置は被攻撃球の表面による近似で、メッシュ上の厳密な接触点ではない。攻撃方向は骨盤間の水平ベクトル。身体同士の物理衝突は有効だが、それだけではHPを減らさない。
- ガード姿勢の腕同士でも物理反応が生じるため、ガードの総変位が常に通常命中より小さくなるとは限らない。追加インパルスは設定倍率に従って軽減される。
- Guardは方向・上段下段を区別しない簡易状態。KOでモーターを停止するが骨盤固定は維持する。移動・相手AI・ラウンド制は未実装。
- 骨盤をワールドへ固定した補助つきの立位であり、自律バランス制御は未実装。肘・膝を含めた可動域は簡易設定。
- アニメーションのTranslation・Scale補間は用意したが、現在の物理リグは回転目標のみを受け取る。Idleは静止姿勢のループ。
- 既存資料とPhase 6までの実装・モデルを初回コミットの対象とする。参考画像とビルド生成物はGitから除外する。
