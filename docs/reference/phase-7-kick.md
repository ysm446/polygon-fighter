更新日時: 2026-09-05 16:08

開発版0.8.0で右脚の前蹴りを追加した。P1はF、P2はL、または各Kickボタンで出す。P/Kのパンチと選び分けられる。Phase 7全体は進行中。

## モーション

男女のBlenderモデルに1.3秒のKickを追加した。膝を引き上げる予備動作、蹴り出した打点の保持、脚を引き戻す反動と立位への収束を分ける。上体を後ろへ傾け、両腕を構える。骨盤は現在の支持位置を保つ。

| 時間 | 目標姿勢 |
| --- | --- |
| 0〜0.15秒 | 脚を少し引き、上体を前へ傾けて準備する |
| 0.15〜0.32秒 | 大腿65度・膝−95度で脚を畳み、上体を後ろへ傾ける |
| 0.32〜0.50秒 | 大腿100度・膝−5度へ伸ばし、前へ蹴り出す |
| 0.50〜0.57秒 | 打点を短く保持する |
| 0.57〜0.72秒 | 大腿65度・膝−85度へ戻し、脚を引き込む |
| 0.72〜1.30秒 | 小さな揺り戻しを経て脚と両腕をIdleへ戻す |

実際の姿勢は物理関節で追従するため、目標より遅れ、接触で変化する。膝と股関節のコーン制限を110度へ広げた。これは共通の簡易制限で、解剖学的な一方向の膝制限や自律バランス制御は後続課題。足滑りと骨盤の支持は[移動資料](phase-7-movement.md)の方式を継続する。

## 戦闘データと判定

| 項目 | Punch | Kick |
| --- | --- | --- |
| Startup / Active / Recovery | 21 / 8 / 31 | 30 / 10 / 38 |
| 全体 | 60フレーム | 78フレーム |
| 通常ダメージ / 硬直 | 12 / 24フレーム | 18 / 30フレーム |
| ガードダメージ / 硬直 | 3 / 8フレーム | 4 / 12フレーム |
| 攻撃部位 | 右前腕の先端 | 右下腿の先端 |
| 判定半径 | 0.18 m | 0.20 m |

AttackKindで技を選び、状態・命中イベント・描画へ伝える。Active中だけ、実際の剛体の位置・回転から拳または足先の球を作る。同じ技は1回だけ命中し、空振りでも復帰まで継続する。

攻撃中は別の技へ切り替えられず、移動も停止する。被弾で技が中断され、アニメーションも解除される。同時命中は両方を先に集め、それぞれの技のダメージと硬直で相打ちにする。ガード・硬直・KO中はキック入力を受け付けない。試合リセットは技とモーションを中断する。

インパルスは従来の共通設定を使い、初期値20 Ns・ガード時5 Ns。キック専用の力倍率やHitstopは未実装。ガードは方向・上段下段を区別しないため、脚へのキックもガードできる。
