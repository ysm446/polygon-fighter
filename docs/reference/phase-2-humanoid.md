# Phase 2 — 物理人形

作成日時: 2026-09-05 14:24
更新日時: 2026-09-05 14:24

## 実装したもの

骨盤・胴体・頭・左右の上腕・前腕・大腿・下腿を11個の動的Box剛体で構成した。身体は約2m、合計67kg。10個のSwingTwistConstraintで接続し、骨盤はFixedConstraintでワールドへ固定する。これは初期段階の安定化補助であり、自律的なバランス制御ではない。

床との衝突は有効。身体内部では直接接続した親子部位のみ衝突を除外し、その他の部位やテスト箱との衝突は有効にする。箱はX=-2m、人形の骨盤はX=0.9mへ配置した。

## Target Poseと関節制御

`src/character/Humanoid.h` に部位の寸法・質量・親・初期位置・関節位置を定義する。今回の立位Target Poseは各親子間の相対回転を単位Quaternionとする。`src/physics/PhysicsRig.*` がJoltの剛体・関節の生成、姿勢リセット、調整、インパルスを管理する。

通常更新では身体のTransformを直接設定せず、関節のPosition Motorが目標回転へ追従する。リセット時だけ初期Transformと速度を設定し、関節のWarm Startもクリアする。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| Stiffness | 600 Nm/rad | 回転ばねの剛性 |
| Damping | 40 Nms/rad | 回転ばねの減衰 |
| Max torque | 120 Nm | モーターのトルク上限 |
| Joint motors | ON | Swing / Twistの追従を有効化 |

JoltのStiffnessAndDampingモードを使う。初期の関節可動域はSwingの2方向が各45度、Twistが±25度。肘・膝も同じ制約を使う簡易構成で、解剖学的に正確な関節ではない。剛性0またはモーターOFFで追従を止めても、関節接続・可動域・骨盤固定は残る。

ImGuiには関節設定、胴体を押すボタン、姿勢リセット、最大関節角度誤差を表示する。キー操作は [README](../../README.md) を参照する。角度誤差は各関節の現在回転と目標回転の差の最大値であり、身体の位置誤差ではない。

## 描画

既存のBox Meshを各部位の寸法とJoltの最終姿勢で描画する。頭・上半身・下半身を色分けし、カメラを近づけた。設定画からのモデル読み込み、BlenderのSkinning、目標Skeletonの独立表示は未実装。

## 検証

Debug / Releaseのビルドと各3件のCTestが成功した。DX12で床・箱・人形・ImGuiの表示をキャプチャで確認した。Debug Layerの警告・エラーは0件。

`humanoid_standing_and_recovery` は以下を検証する。

- 30秒間立位を保ち、位置・Quaternionが有限かつ安定している。
- 胴体へのインパルスで関節が動き、既定設定では目標姿勢へ戻る。
- 剛性・減衰を弱めると、同じインパルスに対する変位が増える。
- モーターOFFで変位が増え、再度ONにすると復帰する。
- リセット後の全身位置が初期値に一致し、その後も安定する。

Debugでの最大関節誤差は、既定設定で約3.36度、弱い設定（剛性60・減衰4）で約45.91度、モーターOFFで約52.32度。既定設定で復帰後は約0.04度。これらは現在の形状・質量・インパルスでの測定値であり、将来のキャラクター性能を規定しない。
