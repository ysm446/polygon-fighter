# Phase 5 — 被弾反応と姿勢復帰

作成日時: 2026-09-05 15:06
更新日時: 2026-09-05 15:06

## 実装した動作

開発版0.5.0ではCombatが確定した命中に対して、命中部位へ位置つきのインパルスを1回適用する。通常は20 Ns、ガード時は0.25倍の5 Ns。身体の位置を直接変更せず、剛体と関節の運動によって上半身が揺れ、既存の関節モーターが目標姿勢へ戻す。

通常被弾では攻撃アニメーションを中断する。ガード被弾では構えを維持し、ガードの目標を一瞬解除しない。KO時はインパルスを適用したうえでモーターを停止する。骨盤の固定は維持するため、自由な転倒や自律バランス制御は今後の対象。

## データと処理

`HitEvent` に命中位置と単位方向を追加した。命中位置は被攻撃球の中心から拳に向いた表面上の点、方向は攻撃者の骨盤から防御者の骨盤へ向く水平ベクトル。中心が重なる場合も有限な方向・位置を生成する。これは球判定に基づく近似で、実際のBoxや最終メッシュとの厳密な接触点ではない。

`PhysicsWorld` が両者の命中イベントへ倍率を適用し、`PhysicsRig::ApplyHit` がJoltの位置指定 `AddImpulse` で該当剛体へ作用させる。命中を先に収集する相打ちの仕組みは維持する。インパルスを与えた次の物理更新から姿勢変化が現れる。

`HitReactionTuning` は力とガード倍率、`HitReaction` は直近の命中イベント・適用ベクトル・表示残りフレームを保持する。表示寿命は固定更新で30フレーム。一時停止中は進まず、試合リセットで消す。調整値はリセットしても維持する。

## 調整と可視化

| UI | 内容 |
| --- | --- |
| Hit impulse | 0〜40 Ns。初期値20。0で追加インパルスなしの比較が可能 |
| Guard impulse scale | 0〜1倍。初期値0.25 |
| Default hit reaction | 上記2値を初期化 |
| Impact point / impulse | 命中位置と方向の表示切り替え |

通常命中を黄色、ガードを青緑色で表示する。大きな印が命中位置、線の先端の小さな印が力の向き。線は1 Nsあたり0.025 mで、命中した瞬間のワールド位置に0.5秒間残す。HUDにはTorso等の命中部位を表示する。

関節の剛性・減衰・最大トルクも既存UIで調整できる。値を弱めたりモーターを切った場合、初期設定と同じ姿勢復帰は保証しない。被弾設定APIは有限値と範囲を検証してから保存する。

## 検証

Debug / Releaseのビルドと各6件のCTestに成功した。`physical_duel` を拡張し、次を確認した。

- 通常命中で20 Ns、ガードで5 Nsを適用し、双方の攻撃方向に対応する。
- 0 Nsでも戦闘ルールは動作し、身体同士の衝突を維持する。
- 通常20 Nsの命中で頭部の最大変位は約0.0389 m。0 Nsではほぼ変位なし。
- ガード時は接触だけで約0.0542 m、5 Nsを加えると約0.0588 m。追加による最大変位の増加は通常より小さい。
- 通常・ガード・逆方向・最大40 Nsで、攻撃開始から300ステップ後の頭部位置が攻撃前から0.02 m以内へ戻る。直接の姿勢リセットは使わない。
- 1攻撃1命中、表示寿命とリセット、非有限値の拒否、繰り返し攻撃によるKOと試合初期化。

変位の値は現在の固定配置・初期関節設定での測定。ガードは腕の姿勢と物理接触も変わるため、総変位の単純比較だけでは軽減を評価しない。

DX12スモークテストでは起動・リサイズ・パンチ・HP減少・正常終了に成功し、Debug Layerの警告・エラーは0件。キャプチャで命中位置と方向、命中部位、調整UIを確認した。UIボタンの手動クリック確認と今回のWARP再実行は未実施。
