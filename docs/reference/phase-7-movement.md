# Phase 7 — 前後移動と間合い

作成日時: 2026-09-05 15:50
更新日時: 2026-09-05 16:10

開発版0.7.0でPhase 7の前後移動を実装した。Phase 7全体は進行中で、0.8.0で[キックと技選択](phase-7-kick.md)も追加した。

## 操作と戦闘

P1はAで後退・Dで前進、P2は左矢印で後退・右矢印で前進する。画面の左右ではなく、相手に対する前後を指定する。両方向を同時に押すと減速停止する。フォーカスを失うと入力を解除し、ImGuiがキーボードを使用している間も移動を抑止する。

移動できるのはIdle中。攻撃・ガード・被弾硬直・KO中は止まる。離れてパンチを出すと空振りし、接近して出すと実際の腕と相手の位置に応じて命中する。既存の予備動作・打点の保持・反動は維持する。

| 項目 | 初期値・仕様 |
| --- | --- |
| 更新 | 物理・戦闘と同じ固定60Hz |
| 前進 / 後退速度 | 0.85 / 0.65 m/s |
| 加減速 | 6 m/s²。戦闘状態による停止は即時 |
| 最小間合い | 骨盤間0.8 m。接近した側の移動だけを制限 |
| ステージ範囲 | 骨盤のワールドZ座標を−3〜2 mに制限 |
| 向き | P1は−Z、P2は＋Z。すれ違い・回り込みなし |
| カメラ | 2体の中間を追い、距離が開くと引く |
| リセット | 初期位置・姿勢・移動速度・内部入力を初期化 |

キーを押したままリセットすると、次の入力更新で移動が再開する。

## 物理と歩行

対戦時の骨盤をKinematic剛体にし、毎ステップMoveKinematicで支持点を動かす。他の10部位はDynamic剛体のまま、関節とモーターで追従する。移動中に手足の位置を直接設定しない。物理実験モードの骨盤は従来どおりワールドへの固定Constraintを使う。

固定高さの骨盤と床摩擦を併用すると、停止後に脚が傾いたまま引っ掛かるため、対戦時の脚は摩擦係数0とした。接触判定は有効。これは支持付きの移動であり、足裏の接地制御・Foot IK・自律バランスは未実装で、足滑りが残る。骨盤自体はインパルスで動かず、上半身と四肢で被弾反応を表す。

男女のBlenderファイルとGLBに0.8秒のWalkループを追加した。左右の大腿を交互に18度振り、膝を最大24度曲げる。実移動速度に応じて再生速度と強さを変え、後退は逆再生し、0.15秒でIdleへブレンドする。境界で止まると足踏みも止まる。GLBを使わない検証用リグには同じ歩行の目標姿勢を用意する。

0.7.0ではIdle / Punch / Guard / Walkの4クリップを出力し、0.8.0でKickを加えた5クリップへ拡張した。制作と再出力の手順は[Blender資料](phase-6-blender.md)を参照する。

## 検証

- `movement_and_spacing`で30 / 60 / 144Hzの描画間隔に対する移動距離、歩行、後退後の空振り、接近後の命中、状態による移動禁止、同時接近、ステージ端、リセットを確認する。
- 後退・前進・攻撃を続けた後、関節誤差が5度未満へ戻る回帰テストを追加した。
- `dx12_movement_smoke`は660物理ステップで、離れて空振り→接近して命中→Idle復帰を実行する。移動中・遠距離・予備動作・打点・反動・最終姿勢の画像を保存する。
- 検証環境と最新のビルド・CTest結果は[進捗](../plan/progress.md)に記録する。

歩行中の腕振り、重心の上下運動、ステップやダッシュ、転倒・起き上がりは後続作業とする。
