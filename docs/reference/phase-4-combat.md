# Phase 4 — 戦闘判定

作成日時: 2026-09-05 14:56

## 実装範囲

開発版0.4.0では、向かい合う2体の物理人形によるパンチ・ガード・HP・硬直・KOを実装した。P1は白、P2は赤。各人形は11剛体・10関節で構成し、骨盤を固定して関節モーターで目標姿勢へ追従する。P2は180度回転した配置で、両者の身体同士の衝突を有効にする。

最終キャラクターは参考画像と[男女の設定画](character-concepts.md)をもとにBlenderで制作する計画。メッシュ・骨格・アニメーション、glTF読み込みとGPU SkinningはPhase 6で扱う。現在のBoxは検証用表示であり、Blenderモデルは未作成。

## 戦闘ルール

| 項目 | 値 |
| --- | --- |
| 更新周期 | 固定60Hz |
| 初期HP | 100 |
| パンチのStartup / Active / Recovery | 21 / 8 / 31フレーム、合計60 |
| 通常ダメージ / 硬直 | 12 / 24フレーム |
| ガード時ダメージ / 硬直 | 3 / 8フレーム |
| 攻撃球の半径 | 0.18 m |
| 被攻撃球の半径 | 胴体0.36、骨盤0.26、頭0.20、四肢0.14 m |

攻撃フレームは0始まりで21〜28だけを有効にする。既存の1秒の物理パンチへ合わせた値であり、SPECの例示値7/3/12とは異なる。`AttackData` にまとめており、現時点ではコードで調整する。対戦中のアニメーションは1倍速に固定する。

状態はIdle・Attacking・Guarding・Hitstun・KO。Idleからのみ攻撃を開始する。命中は1攻撃につき1回まで。ガードは方向や上段下段を区別しない簡易方式で、ガード硬直終了時に入力が残っていればGuardingへ戻る。HPは0未満にならず、KO後は行動と追加被ダメージを禁止する。

## 処理と責務

- `src/combat/CombatSystem.*`：Jolt・DX12に依存しない戦闘状態、フレーム進行、球交差判定、ダメージ処理。
- `src/physics/PhysicsWorld.*`：2体の生成、入力と目標姿勢の接続、物理更新後の姿勢取得、命中イベントの反映。
- `src/physics/PhysicsRig.*`：配置・向きを持つ剛体と関節、ガード目標、被弾時のアニメーション中断。
- `src/render/RenderScene.h` とRenderer：2体の物理姿勢と目標姿勢、球形の判定表示。
- DebugUI / Main：HP・状態・硬直のHUD、入力、リセット、物理実験モード。

各固定ステップでは目標姿勢の更新、物理更新、命中の収集、戦闘状態への反映の順に処理する。攻撃球は実際の右前腕の先端、被攻撃球は各剛体の実際の中心から生成する。手ボーンはまだないため、前腕端を拳の代理として扱う。目標アニメーションだけが伸びても命中しない。

両者の命中を収集してから反映するため、同じフレームの相打ちを扱える。被弾時は攻撃を中断し、KOでは関節モーターを停止する。試合リセットでHP・状態・姿勢を戻し、現在の関節設定を再適用する。骨盤の固定はKOでも維持する。

身体の物理接触だけではダメージを発生させない。命中時に加える追加インパルスとガード時の軽減はPhase 5で実装する。固定フレームの攻撃進行は描画速度に依存しないが、物理計算全体の完全な決定性は保証しない。

## 操作と表示

P/KでP1/P2がパンチ、G/Oの長押しまたはAuto guardでガード、RまたはReset matchで試合を初期化する。Spaceで一時停止し、Nで1ステップ進められる。判定表示は橙色が攻撃球、青色が被攻撃球。攻撃球は直前に評価した有効フレームを表示する。

`--physics-lab` では従来の箱と1体の実験を起動する。このモードでのみ再生速度を0.25〜2倍へ調整できる。詳細な起動・操作手順は[README](../../README.md)を参照する。

## 検証結果

Debug / Releaseのビルドと各6件のCTestに成功。戦闘ルールの単体テストでは正確な有効期間、空振り、重複命中防止、ガード、相打ち、硬直、KOとリセット、30/60/144Hz相当の描画間隔を確認した。

Jolt上の2体のテストでは双方向の物理パンチ、通常12・ガード3ダメージ、物理接触だけではHPが変わらないこと、モーターOFFでは目標だけで命中しないこと、KOと試合リセットを確認した。既存の物理・アニメーションテストも成功した。

NVIDIA RTX PRO 5000 BlackwellでDX12の起動・リサイズ・パンチ・正常終了を確認し、Debug Layerの警告・エラーは0件。パンチ中のキャプチャで2体、攻撃球、HP 100/88、硬直表示を確認した。各UIボタンの手動クリック確認は未実施。WARPはPhase 1で確認済みだが、今回は再実行していない。
